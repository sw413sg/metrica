# Beats grabados

Cuatro loops con licencia CC0, bajados y empaquetados con la app. No se streamean. Se pueden usar en Métrica, que es de pago, sin pagar ni pedir permiso. El mp3 del repo es el mismo audio, normalizado para que suenen parejo y cortado a un número entero de compases para que el loop no se desfase.

La licencia es [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/): dominio público. No exige atribución. Igual figura el autor.
